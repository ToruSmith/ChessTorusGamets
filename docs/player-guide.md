## 安裝到手機或電腦

安裝後會出現在主畫面，打開時沒有網址列；第一次載入完成後，**沒有網路也能玩**（線上對戰除外）。

| 裝置                 | 做法                                                              |
| -------------------- | ----------------------------------------------------------------- |
| iPhone／iPad         | 用 Safari 打開網址 → 點「分享」→「加入主畫面」                    |
| Android              | 用 Chrome 打開網址 → 右上角選單 →「安裝應用程式」或「加到主畫面」 |
| 電腦（Chrome、Edge） | 網址列右側的「安裝」圖示                                          |

## 遊戲模式

| 模式     | 內容                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| 雙人同機 | 一台裝置輪流下。可以悔棋（不計時時）、翻轉棋盤、提和、認輸、聲明和棋。            |
| 線上對戰 | 開房間把連結傳給朋友，或從大廳加入公開房間。見[和朋友線上對戰](#和朋友線上對戰)。 |
| 電腦對手 | 和 Stockfish 對弈，1 級最容易、8 級是全力。可以要提示；不計時的對局可以悔棋。     |
| 戰術題   | 16 題一步殺與兩步殺。只要能在規定步數內將死都算對，不限一種解法。                 |
| 賽後分析 | 下完的對局都能分析，也能貼上 PGN 分析別人的棋。                                   |

雙人同機與電腦對手下到一半關掉也沒關係，重新打開會接著下。電腦的開局會參考 Lichess 的開局資料，每盤都有變化。

## 時制

不計時、3 分鐘＋每步 2 秒、5 分鐘、10 分鐘、15 分鐘＋每步 10 秒、30 分鐘。
「＋每步 N 秒」是每走一步加回 N 秒。計時的對局不能悔棋。

## 勝負與和棋

依國際棋聯（FIDE）的正式規則。重點是分清楚「自動結束」與「要聲明才算」。

**自動結束**：

- **將死**：被將死的一方輸。
- **逼和**：輪到的一方沒有被將軍，卻沒有任何合法的棋可走，和棋。
- **死局面**：雙方都不可能將死對方（例如王對王、王加一個主教或騎士對王），和棋。
- **五次重複**：同一局面出現第五次，和棋。
- **75 回合**：雙方各走 75 步都沒有吃子、也沒有動兵，和棋。
- **超時**：時間用完的一方輸；但如果對手不可能將死他，判和。

**要聲明才算**（由輪到走棋的一方按「聲明和棋」）：

- **三次重複**：同一局面出現第三次。
- **50 回合**：雙方各走 50 步都沒有吃子、也沒有動兵。

如果是「走了這一步才會成立」，畫面會問你要不要「走這步並聲明和棋」。條件不成立時，對局繼續。

**提和**：提出後不能收回；對手直接走下一步就等於拒絕。

## 和朋友線上對戰

1. 點「線上對戰」→「建立房間」，選時制與顏色（白方、黑方或隨機）。
   勾選「公開在大廳」的話，其他人也能從大廳加入。
2. 把畫面上的連結或房號傳給朋友，朋友打開後按「加入對局」，對局開始。

對局中：

- **斷線或重新整理**：用同一台裝置、同一個瀏覽器回到原本的連結，就會回到同一盤棋。時間由伺服器記錄，斷線時你的時間會繼續走。
- **提和、聲明和棋、認輸**都可以用；線上不能悔棋。
- **再來一局**：結束後雙方都同意，會開一盤新的並交換顏色。
- **觀戰**：兩個座位都坐滿後，其他人打開連結就是觀戰，只能看不能下。
- **公平**：線上對局進行中，網站不提供任何引擎分析或提示，結束後才能分析。

## 賽後分析與 PGN

- 對局結束後按「賽後分析」。電腦會看完每一手，畫出**白方勝率走勢**、顯示評估條與推薦手的箭頭，
  並把失誤標成不精確（?!）、錯著（?）、大錯（??），也會顯示開局名稱。
- 用鍵盤的左右方向鍵可以逐手瀏覽。
- 可以**複製或下載 PGN**；在賽後分析頁面按「匯入 PGN」，貼上棋譜就能分析其他對局。

## 操作

- 走子可以**點選**（先點棋子再點目的地），也可以**拖曳**。兵走到底線時會問要升變成哪一種棋子。
- 頁面上的「English」／「繁體中文」按鈕可以切換介面語言。

## 常見問題

**線上對戰一直連不上？**
先確認網路正常，再重新整理頁面。學校或公司網路有時會擋住即時連線，換成手機網路試試看。

**為什麼看到的還是舊版本？**
遊戲會先用裝置上的快取，讓沒有網路時也能開。新版本會在下一次開啟時生效，把分頁或 App 完全關掉再開一次即可。

**重複了三次，為什麼沒有和棋？**
三次重複與 50 回合要由輪到的一方按「聲明和棋」才算。不聲明的話，對局會一直進行到五次重複或 75 回合時自動和棋。

**電腦太強？**
從 1 級開始，贏了再往上調；也可以按「提示」看看電腦會怎麼走（線上對局沒有提示）。

**第一次用電腦對手比較慢？**
第一次要載入 Stockfish 引擎（數 MB），之後就存在裝置上，離線也能用。

## 你的資料

- **不需要帳號**。遊戲不收集姓名、電子郵件，也沒有廣告或追蹤程式。
- **線上對戰**時，會用 Firebase 匿名登入取得一組隨機代號。房間裡存的是：這組代號、時制與顏色設定、棋步與時間、
  提和／認輸／聲明和棋／再來一局的紀錄。房間不存名字；任何拿到房號的人都看得到棋局，公開房間也會出現在大廳。
- **未下完的棋、要分析的對局與戰術題進度**只存在你的瀏覽器裡，不會上傳。
